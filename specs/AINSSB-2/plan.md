# Implementation Plan: Repository scaffold: README section and health-check script

**Branch**: `AINSSB-2-repository-scaffold-readme-section-and-h` | **Date**: 2026-11-02 | **Spec**: [spec.md](spec.md)

## Summary

Add a stdlib-only `scripts/healthcheck.py` that prints `ok` and exits 0, a pytest test that imports it and asserts the output, a `pyproject.toml` declaring pytest as the only dev dependency, and a "Health check" README section. No application code, no framework, no CI changes.

## Technical Context

- **Language/Version**: Python `>=3.12` (matches `python-version: "3.12"` in `.github/workflows/ci.yml`; resolves the spec's open question)
- **Primary Dependencies**: none at runtime (standard library only)
- **Dev dependencies**: `pytest` only, declared in a PEP 735 `[dependency-groups] dev` group (`uv run` installs the `dev` group by default)
- **Testing**: pytest, run via `uv run pytest` from the repo root
- **Project type**: single script plus tests; non-packaged project (no `[build-system]`, so uv treats it as a virtual project and nothing is built or installed)
- **Constraints**: script prints only `ok\n`, needs no env vars; FR-006 forbids touching `.github/`, `.specify/`, `.claude/`, `CLAUDE.md`

## Constitution Check

`.specify/memory/constitution.md` is still the unfilled template, so it defines no gates. The rules in `CLAUDE.md` apply and are satisfied: no secrets, protected paths untouched, code and tests in the stated locations, no new dependencies. No violations.

## Design Decisions

1. **Script shape**: `scripts/healthcheck.py` defines `main() -> int` which prints `ok` and returns 0, with `if __name__ == "__main__": sys.exit(main())`. Importing has no side effects, so the test can call `main()` directly.
2. **Import mechanism** (spec edge case): set `pythonpath = ["scripts"]` and `testpaths = ["tests"]` under `[tool.pytest.ini_options]` in `pyproject.toml`; the test does `import healthcheck`. No package install and no `sys.path` hacking. Rejected alternative: `importlib.util.spec_from_file_location` (more boilerplate).
3. **Test**: uses `capsys` to assert `main()` returns 0 and stdout is exactly `"ok\n"`. A second test runs `python scripts/healthcheck.py` via `subprocess` with `sys.executable` to prove the documented command and exit status. Changing the output makes both fail (US2 scenario 2).
4. **Ruff** (open question): follow the story, so ruff is NOT declared. `uv run ruff check .` is not guaranteed to work from the project environment. Use `uvx ruff check .` locally and document that in the README. The code is kept ruff-clean by default rules. Needs a human decision if `uv run ruff` must work (it would require a second dev dependency, contradicting FR-004).
5. **README**: append a `## Health check` section with the command `python scripts/healthcheck.py` (or `uv run python scripts/healthcheck.py`), expected output `ok`, exit status 0, and the `uv run pytest` command.
